# Изображения галереи графиков

Изображения с именами `01.png`–`15.png` заменяют SVG-заглушки в движущихся колонках на главной странице и на странице галереи. Названия и описания задаются в `src/components/ChartGallerySection.tsx`.

Добавлены предоставленные пользователем изображения:

- `03.png` — «ИИ и закон Мура», оригинал `Moore ded2.png`.
- `10.png` — «География выручки ASML по ключевым рынкам, 2015–2025», оригинал `rev by reg.png`.

У заполненных карточек `fullSize: true`: изображение открывается в полном размере по нажатию. Изображения отображаются целиком, без обрезки.

Рекомендуемый формат:

- PNG;
- соотношение сторон 4:3 или 16:9;
- ширина от 800 px;
- без внешних полей вокруг графика.
