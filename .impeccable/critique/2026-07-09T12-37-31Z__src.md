## Главные проблемы

- **P1:** повторяющиеся X по умолчанию теряют все наблюдения, кроме первого; управление агрегацией скрыто.
- **P1:** range/confidence/bubble незаметно превращаются в более простой график при нехватке полей.
- **P1:** обычная area chart может начинать заливку от обрезанной шкалы, визуально преувеличивая различия.
- **P1:** scatter/bubble допускают текстовый X и могут показать пустой холст без объяснения.
- **P1:** у графиков нет доступного текстового эквивалента или связи с таблицей данных.
- **P1:** мобильный auto-fit уменьшает холст до `322×242`, делая подписи слишком мелкими.
- **P1:** scatter имеет два конкурирующих механизма подписей точек.
- **P2:** выбор типа отмечается только CSS-классом, без `aria-pressed`.
- **P2:** детальные E2E-проверки неравномерны; один тест уже устарел.

## По типам

### Сравнение

- **Столбцы:** теряют дубли X. Добавить обязательный выбор агрегации при дублях.
- **Столбцы с накоплением:** не предупреждают, что показатели должны быть аддитивными и иметь общую единицу. Добавить проверку совместимости и сортировку по сумме.
- **Нормированные столбцы:** отрицательные значения дают диапазон `-100…100`, хотя модель обещает «каждый столбец — 100%». Переключать описание на расходящийся 100% stack.
- **Линейчатая:** наследует потерю дублей. Автоматически рекомендовать для длинных категорий и добавить сортировку.
- **Линейчатая с накоплением:** сложно сканировать длинные списки без сортировки по итогу. Добавить сортировку по сумме/ряду.
- **Нормированная линейчатая:** те же неверные ожидания при отрицательных данных. Добавить предупреждение и расходящийся режим.

### Тренды

- **Линия:** режим пропусков реализован, но недоступен в UI. Открыть `gap/zero/connect` с пояснением последствий.
- **Сглаженная линия:** фиксированное сглаживание может внушать ложную непрерывность. Добавить короткое предупреждение; слайдер пока не нужен.
- **Ступенчатая линия:** нет подсказки, что значение сохраняется до следующего наблюдения. Добавить эту семантику в предпросмотр типа.
- **Диапазон между линиями:** молча берёт первые две метрики и с одной метрикой становится обычной линией. Требовать явные нижнюю и верхнюю линии.
- **Ступенчатый диапазон:** наследует неявный выбор границ. Требовать две линии и пояснять момент перехода интервала.
- **Линия с интервалом:** неполная группа становится обычной линией; перевёрнутые границы визуально исправляются и скрывают ошибку данных. Валидировать `lower ≤ main ≤ upper`.

### Области

- **Область:** автоматическая шкала не обязана включать ноль. По умолчанию строить area от нулевой базы.
- **Области с накоплением:** сравнивать можно в основном нижний слой; смешанные знаки особенно нечитабельны. Предупреждать об аддитивности и предлагать линии для сравнения.
- **Нормированные области:** смешанные знаки разрушают смысл «целого». Запрещать либо явно обозначать расходящуюся композицию; включать прямые подписи при малом числе рядов.

### Связи

- **Точечный:** текстовый X удаляет все точки; доверительная полоса доступна даже при двух наблюдениях; подписи дублируются двумя настройками. Ограничить поля, объединить подписи, ввести минимум выборки для интервала.
- **Пузырьковая:** без поля размера не отличается от scatter; отрицательные размеры превращаются в положительные диаметры. Требовать неотрицательное поле размера и кодировать величину площадью круга.

## Персоны

- **Alex, опытный аналитик:** скрытая агрегация и отсутствие сортировки заставляют готовить данные вне редактора; семантические fallback-и подрывают доверие.
- **Sam, keyboard/screen reader:** график не имеет доступного имени, описания и связи с таблицей; выбранный тип не объявляется как выбранный.
- **Riley, стресс-тестер:** дубли X, текстовый scatter X, отрицательные bubble sizes и неполные интервалы проходят без ошибок и создают неверный результат.
