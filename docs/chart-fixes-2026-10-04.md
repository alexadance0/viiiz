# Исправления после аудита графиков — 4 октября 2026

Исправлены десять подтверждённых проблем из [исходного аудита](chart-audit-2026-10-03.md). Материалы до исправлений сохранены отдельно в `output/chart-audit-2026-10-03/before-fixes`; исходный отчёт ссылается на них.

| Проблема | Изменение |
| --- | --- |
| A01: обрезание центрированного текста | Заголовок, подзаголовок, примечание и источник получают координату, соответствующую выравниванию. Проверены все 54 типа и три положения текста. |
| A02: HTML в предпросмотре отличается от экспорта | Форматированный текст в ChartCanvas и экспорте использует одну SVG-отрисовку. Высота строки учитывает самый крупный фрагмент; длинные слова переносятся, фон и подчёркивание сохраняются. Редактор текста продолжает работать с HTML. |
| A03: наружные значения горизонтальных нормированных полос обрезаются | Расчёт поля для наружных подписей учитывает фактическую ширину текста и индивидуальные стили, включая подписи, включённые для отдельных значений. |
| A04: название вертикальной оси butterfly за пределами холста | Для внутреннего расположения категорий задана координата бокового названия оси. |
| A05: холодная загрузка moving-average-scatter | Загрузчик импортирует модуль scatter вместе с line. Проверка выполняется без App и фоновой предзагрузки всех модулей. |
| A06: горизонтальные категории превращаются в столбцы букв | Перенос рассчитывается по ширине поля подписей. Высота ограничена шагом категорий; лишние строки заменяются многоточием. На узкой числовой оси скрываются пересекающиеся подписи. |
| A07: NaN при анимированном включении среднего | Если ряд начинается с пропусков, конечная подпись привязана к последнему существующему значению. Подписи пропусков и полностью пустых рядов выключены. Анимация графика сохраняется. |
| A08: невалидное имя Source Sans 3 | Имя заключено в кавычки. Сохранённые конфигурации с числовыми именами семейств нормализуются при отрисовке. |
| A09: курсив отличается в SVG | Предпросмотр и экспорт используют одинаковый синтез курсива. Для удалённых шрифтов загружается курсив; при отсутствии отдельного начертания экспорт использует тот же синтез, что и предпросмотр. |
| A10: truncate не сокращает подписи | Оси получают ограничение ширины при сокращении. Воспроизведение с шестью длинными названиями теперь показывает шесть сокращённых подписей внутри холста. |

## Проверка

- Production build и TypeScript проходят.
- 868 модульных тестов проходят; тяжёлый исходный аудит отдельно выключен по умолчанию.
- Повторная матрица: 54 типа × 21 компоновка = 1134 сценария. Ошибок выполнения и видимого текста за пределами холста нет.
- 270 комплектов предпросмотр → SVG → PNG: размеры совпадают. Остаточные различия отдельных графиков не превышают 0,125% пикселей при пороге различия канала 24/255. Это не утверждение о полном побитовом совпадении всех изображений.

- Переключение всех 54 типов в редакторе с включённой анимацией: ошибок нет.
- Добавлены постоянные проверки холодной загрузки, всех положений общего текста и узкой горизонтальной компоновки. Исходные опциональные проверки шрифтов, сокращения и переходов теперь содержат утверждения, проверяющие результат.
